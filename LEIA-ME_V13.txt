PRÓXIMA ETAPA
Vamos adicionar uma imagem por vez:
1. escolher a obra;
2. subir a imagem com nome definido;
3. alterar somente o image daquela obra;
4. testar no site;
5. passar para a próxima.

COMO SUBIR
1. No GitHub, abra worker.js.
2. Apague todo o conteúdo.
3. Cole o worker.js desta versão.
4. Commit changes.
5. Aguarde o deploy.
6. Atualize o site.

Não precisa executar SQL.
